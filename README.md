# Middle Earth Character Profiles Web App

This is a full-stack web application that allows users to manage character profiles from J.R.R. Tolkien's *The Lord of the Rings* and *The Hobbit*. Users can create, update, and delete profiles, each containing a picture, detailed information, and an optional biography. Additionally, the app supports sorting and categorizing characters by attributes such as **Location** and **Race** (ie Hobbit, Orc), with the flexibility to add new categories.

## Features

- **Create, Update, and Delete Character Profiles**  
  Users can add detailed character profiles, including a picture and other essential details.

- **Character Biographies**  
  Click on the book icon in each profile to access or add a biography.

- **Dynamic Categorization**  
  Characters can be sorted by attributes such as **Location** or **Race**. If a category does not exist, users can create it dynamically.

## Technologies Used

- **Frontend**: React.js
- **Backend**: ASP.NET Core Web API
- **Database**: Microsoft SQL Server
- **Styling**: Bootstrap
